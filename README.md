# Smart Array & Number Theory Toolkit

A Python-based modular toolkit designed for fundamental algorithms and array techniques, aligned with academic problem-solving and programming curriculum requirements.

## Project Structure
- `main.py`: Interactive command-line menu interface with error handling.
- `algorithms.py`: Core mathematical and fundamental algorithms (Prime, GCD, Fibonacci, Factorial).
- `array_ops.py`: Advanced array manipulation techniques (Reversal, Duplicate Removal, K-th Smallest Element).

## Features & Modules
1. **Fundamental Algorithms:** Prime number testing via square-root optimization, Euclidean GCD calculation, Fibonacci sequence generation, and factorials.
2. **Array Operations:** In-place/slicing array reversal, duplicate removal using sets, and sorting-based $K^{th}$ smallest element lookup.
3. **Robust Input Handling:** Built-in `try-except` validation blocks to prevent runtime crashes from invalid user inputs.

1. Ensure Python is installed on your system.
2. Open your terminal in the project directory.
