# Project Problem Statement & Scope

## Project Title
**Smart Array & Number Theory Toolkit**

## 1. Introduction & Objective
The objective of this project is to develop a modular, command-line-driven software utility in Python that implements core mathematical algorithms and array manipulation techniques. This project directly addresses fundamental concepts learned in programming coursework, ensuring high academic safety and zero-rejection risk.

## 2. Problem Definition
Students often encounter complex number-theoretic operations and sequential data management challenges. This toolkit solves these challenges by providing an interactive, centralized interface to execute, test, and analyze standard operations like prime verification, greatest common divisors, sequence generation, and array reorganization efficiently.

## 3. Scope & Syllabus Alignment
The project implements the following mandatory components:
- **Fundamental Algorithms:** Factoring methods, prime checking via optimized square-root bounds, Euclidean algorithm for GCD, and recursive/iterative factorial and Fibonacci number generation.
- **Array Techniques:** Array order reversal, duplicate elimination, and ranking algorithms (finding the $K^{th}$ smallest element).
- **Software Engineering Practices:** Separation of concerns using a multi-file modular architecture (`main.py`, `algorithms.py`, `array_ops.py`), alongside robust input validation (`try-except`) for enhanced user experience.
